Tu wrzuć oficjalne logo programów (SVG, w ostateczności PNG), a następnie zaimportuj je w `src/config/software.ts` (pole `logo`).
Do czasu podmiany strona pokazuje placeholder z ikoną obrazka z krzyżykiem i nazwą programu pod spodem.
Brakuje obecnie: Program Płatnik, Fakturownia.pl, Legalis księgowość kadry biznes.
Przed użyciem oficjalnych logo sprawdź wytyczne producentów (zasady użycia znaków towarowych; Płatnik to program ZUS).
