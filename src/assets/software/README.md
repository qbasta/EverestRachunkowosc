Tu wrzuć oficjalne logo programów (SVG/PNG), np. `symfonia.svg` i `enova365.svg`,
a następnie zaimportuj je w `src/config/software.ts` (pole `logo`).
Do czasu podmiany strona pokazuje neutralną plakietkę z nazwą programu.
Przed użyciem oficjalnych logo sprawdź wytyczne producentów (zasady użycia znaków towarowych).
